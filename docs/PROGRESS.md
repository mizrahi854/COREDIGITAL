## בדיקות שהורצו בפועל (2 באוקטובר 2026)
- `npm run typecheck`: עבר
- `npm run build`: עבר. נשאר רק אזהרה על גודל ה־bundle (כ־755KB לפני דחיסה, כ־216KB אחרי gzip)
- `npm run lint` (oxlint): אפס שגיאות. נשארו אזהרות סגנון בלבד: only-export-components, set-state-in-effect, purity של `Date.now`
- `npm test` (Vitest): 21 מתוך 21 עברו
  - `tests/booking.test.ts`: זמינות, הפסקות, חסימות, חפיפות, פקיעה, מקדמה, אישור ידני, ביטול, שינוי מועד אטומי
  - `tests/permissions.test.ts`: יצירת תוכן, אורח/ת, עריכת תוכן של עסק אחר, צוות, ביקורות, שיחות
- `npm run test:e2e` (Playwright, Chromium, Pixel 7): 14 מתוך 14 עברו
  - המסעות 1–12 מ־§19 (חלקם מאוחדים בבדיקה אחת)
  - כשל תשלום מדומה ואחריו הצלחה
  - בקשה שממתינה לאישור
  - Google Calendar מדומה: חיבור, כשל, ניתוק
  - הודעות ״לא נקרא״
- סקריפט שעובר על כל המסכים של כל התפקידים ב־360px וב־1280px: אין גלישה אופקית ואין שגיאות קונסול

## באגים שנמצאו ותוקנו בבדיקות
- selector לא יציב ב־Zustand (בורר עיר) גרם ללולאת רינדור
- סימון התראות כנקראו הפעיל את ה־effect מחדש בלולאה
- פעולות ללא ערך החזרה דיווחו כשל במקום הצלחה (`mutate` מחזיר עכשיו `true`)
- מעבר בין קישורי הזמנה לאותו עסק עם פרמטרים שונים לא אתחל את הטיוטה
- גלישה אופקית בצ׳יפים של ניהול התוכן
- כפתור ״קביעת תור״ הוצג לבעל העסק על התוכן של העסק עצמו; עכשיו מוצג ״עריכת הפוסט״
